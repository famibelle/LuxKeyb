Où trouver l'application

Le Lëtzebuergesch Clavier s'installe depuis Google Play, comme n'importe quelle autre application, avec les mises à jour automatiques. Chaque version est aussi publiée sur les releases GitHub avec son APK signé, dès qu'elle est prête, pour qui veut l'avoir avant que Google Play ne la distribue. Le guide d'installation explique la manipulation.

💡 L'APK publié sur GitHub est construit par l'intégration continue à partir du code de ce dépôt, et signé avec la clé de production. Rien d'autre n'y est ajouté : pas de publicité, pas de traceur, et rien de ce que vous tapez ne sort de l'appareil ; seule la voix part, quand vous dictez. Vous pouvez le vérifier, tout le code est ouvert.
