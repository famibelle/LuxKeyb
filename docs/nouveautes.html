Où trouver l'application

Le Lëtzebuergesch Clavier n'est pas encore sur le Play Store. Il se télécharge depuis les releases GitHub, où chaque version est publiée avec son APK signé, dès qu'elle est prête. Le guide d'installation explique la manipulation, qui prend une minute.

💡 L'APK publié est construit par l'intégration continue à partir du code de ce dépôt, et signé avec la clé de production. Rien d'autre n'y est ajouté : pas de publicité, pas de traceur, aucune donnée qui sorte de l'appareil. Vous pouvez le vérifier — tout le code est ouvert.
