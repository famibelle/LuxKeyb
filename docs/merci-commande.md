# Merci ! 🎉

<p class="chapo">Votre commande est reçue et payée. Voici ce qui se passe
maintenant.</p>

1. **Tout de suite**, Stripe vous envoie le reçu de votre paiement par e-mail.
2. **Sous deux jours ouvrés**, nous vous écrivons avec le numéro de votre
   commande et le **code** de chaque boîte : scanné dans le carnet de
   l'application (« 🎁 Recevoir », puis « 🃏 Le code d'une carte en papier »),
   il y ajoute les cartes de la boîte.
3. **Votre boîte est imprimée** pour vous, puis envoyée directement chez vous
   par l'imprimeur : comptez deux à trois semaines.

Vous pouvez renoncer à votre achat dans les 14 jours qui suivent la
réception : répondez simplement à notre e-mail.

En attendant la boîte, lisez [la règle du jeu](regle-du-jeu.html) : vous
pourrez jouer dès l'ouverture.
