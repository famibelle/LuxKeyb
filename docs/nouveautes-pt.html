Onde encontrar a aplicação

O Lëtzebuergesch Clavier instala-se a partir do Google Play, como qualquer outra aplicação, com atualizações automáticas. Cada versão é também publicada nas releases do GitHub com o seu APK assinado, assim que está pronta, para quem a quiser antes de o Google Play a distribuir. A página inicial explica como.

💡 O APK publicado no GitHub é construído pela integração contínua a partir do código deste repositório, e assinado com a chave de produção. Nada mais lhe é acrescentado: sem publicidade, sem rastreadores, e nada do que escreve sai do aparelho; só a voz sai, quando dita. Pode verificá-lo, todo o código é aberto.
