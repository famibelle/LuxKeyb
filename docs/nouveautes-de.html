Wo es die App gibt

Lëtzebuergesch Clavier wird wie jede andere App über Google Play installiert, mit automatischen Updates. Jede Version wird außerdem, sobald sie fertig ist, mit ihrer signierten APK in den GitHub-Releases veröffentlicht, für alle, die sie haben möchten, bevor Google Play sie verteilt. Die Startseite erklärt, wie es geht.

💡 Die auf GitHub veröffentlichte APK wird von der Continuous Integration aus dem Code dieses Repositorys gebaut und mit dem Produktionsschlüssel signiert. Nichts anderes kommt hinzu: keine Werbung, kein Tracker, und nichts, was Sie tippen, verlässt das Gerät; nur die Stimme geht hinaus, wenn Sie diktieren. Sie können es überprüfen, der gesamte Code ist offen.
