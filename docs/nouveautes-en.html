Where to get the app

Lëtzebuergesch Clavier installs from Google Play, like any other app, with automatic updates. Each version is also published on the GitHub releases with its signed APK, as soon as it is ready, for anyone who wants it before Google Play rolls it out. The home page explains how.

💡 The APK published on GitHub is built by continuous integration from the code in this repository, and signed with the production key. Nothing else is added: no ads, no trackers, and nothing you type leaves the device; only your voice does, when you dictate. You can check for yourself: all the code is open.
